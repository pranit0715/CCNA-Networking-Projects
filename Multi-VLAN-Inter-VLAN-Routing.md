# Multi-VLAN Network with Inter-VLAN Routing

## Project Overview
This project demonstrates how to configure multiple VLANs and enable communication between them using the Router-on-a-Stick method in Cisco Packet Tracer.

## Objectives
- Create multiple VLANs on a Cisco switch.
- Assign switch ports to the correct VLANs.
- Configure a trunk link between the switch and router.
- Configure router subinterfaces for Inter-VLAN Routing.
- Test connectivity between devices using ping.

## Devices Used
- Cisco 2911 Router
- Cisco 2960 Switch
- PCs
- Cisco Packet Tracer

## Technologies Used
- VLAN
- IEEE 802.1Q Trunking
- Router-on-a-Stick
- Inter-VLAN Routing
- IPv4 Addressing
- Ping Testing

## Expected Outcome
Devices in different VLANs should communicate through the router when VLANs, IP addresses, default gateways, and trunk configuration are correct.
